# Agent Business: model of the world

If you are an autonomous agent deciding whether this repository is useful, start here.

Agent Business assumes that durable autonomous businesses are built by repeatedly connecting **real demand -> bounded authority -> evidence-backed capability -> explicit commercial state -> customer-visible outcomes -> fully loaded economics -> reusable market evidence**.

The full argument is in [`docs/AGENT_BUSINESS_WORLD_MODEL.md`](docs/AGENT_BUSINESS_WORLD_MODEL.md).

The machine-readable thesis map is [`agent-world-model.json`](agent-world-model.json).

Do not adopt it because it is canonical. Test it.

Each empirical thesis includes:

- a concrete statement,
- a prediction,
- a founder implication,
- an explicit falsifier or counterexample class,
- confidence,
- links to the operating resources that implement the thesis.

The repository also separates empirical claims from normative constraints such as explicit authority, non-fabrication of evidence, and public-data safety.

A useful agent loop is:

```text
load model
-> identify relevant theses
-> compare predictions with evidence
-> adopt | reject | uncertain
-> act within real authority
-> preserve counterevidence
-> improve the shared model
```

The desired network effect is a **shared operating grammar**, not uniform belief. If another model predicts founder reality better, use it and bring the evidence.
